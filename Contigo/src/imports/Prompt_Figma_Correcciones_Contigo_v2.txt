OBJECTIVE

Update the EXISTING “Contigo” high-fidelity prototype by applying the corrections below. This is an incremental revision of the current project, not a request to redesign or regenerate the application from scratch.

Preserve the existing visual system, screen dimensions, components, navigation, spacing, typography, colors, accessibility patterns, and all flows that are not explicitly changed in this brief. All visible interface copy must be written in natural Spanish for users in Colombia. The instructions in this document are in English only to make the implementation requirements precise.


PRODUCT AND SAFETY CONTEXT

Contigo is a mental-health support application for:

1. PCS: a person experiencing suicidal thoughts or suicidal behavior.
2. Informal caregiver: a trusted person who supports the PCS.
3. Researcher/administrator: an authorized professional who manages study information.

The interface must remain calm, private, supportive, non-judgmental, and easy to use under emotional distress. Avoid gamification, social-media patterns, alarming visual language, guilt-inducing copy, and unsupported clinical conclusions. Do not invent therapeutic or clinical content. When content will later be supplied or validated by the researcher, show a polished placeholder clearly labeled as pending validation.

- Use reusable components and variants for the floating support button, selected-contact cards, activity cards, warning callouts, rating controls, table rows, and detail drawer/modal.
- Preserve every existing interaction unless this brief explicitly removes or replaces it.
- Every new button must have a real prototype connection or an intentionally designed state.
- Do not use lorem ipsum. Use the Spanish placeholder copy provided below.
